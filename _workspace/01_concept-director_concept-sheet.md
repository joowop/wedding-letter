# 컨셉 디렉션 노트 — "봄바람에 살랑이는 개나리의 약속"

## 톤앤매너

2027년 4월 17일 토요일, 개나리가 한창인 봄날의 예식. 사용자의 "봄 살랑살랑" 요청을 최우선으로 두어 **가볍고 산뜻하고 화사한 spring breeze** 무드를 만든다. 예식장은 파티움하우스 수원(웨딩홀)이며 격식은 단정함 정도로만 유지하고, 무겁거나 격식 일변도가 되지 않게 한다. 따뜻한 크림 아이보리 위에 맑은 개나리 노랑과 막 돋은 연두 새순을 얹어 "햇살 좋은 봄 오후"의 공기를 담되, 노랑은 일러스트·꽃잎·장식에만 쓰고 글자는 짙은 갈색/올리브로 또렷하게 읽히게 한다. 한글은 Nanum Myeongjo의 단정한 균형을 유지해 어른 세대도 편안하게 읽을 수 있도록 한다.

## 핵심 비주얼 컨셉

- **컬러 키 무드**: cream ivory 배경(#FFFBF1) + butter cream 면(#FBF1D6) 위에 forsythia yellow(#F2C230)가 일러스트와 꽃잎으로 화사하게 퍼지고, spring sprout green(#B4C77A)이 디바이더와 새순으로 생기를 더한다. 텍스트 강조와 버튼은 deep olive(#5F6B2C), 본문은 warm dark brown(#3B3022).
- **타이포 키 무드**: 기존 조합 유지(바꿀 뚜렷한 이유 없음 — 세리프+스크립트 조합이 봄 무드에도 충분히 가볍고, 유지 시 프론트엔드 변경 범위 최소화). Allura 스크립트가 "살랑이는" 손글씨 느낌을 담당.
- **이미지 키 무드**: 휘어 늘어진 가는 가지에 네 갈래 노란 꽃과 연두 새순이 달린 워터컬러 개나리. 넉넉한 여백과 흩날리는 꽃잎 몇 장.
- **모션 키 무드**: "봄바람에 살랑이는" — 노란 꽃잎이 좌우로 팔랑이며 흩날리고, 가끔 부는 봄바람에 살짝 쏠렸다 돌아온다.

- 꽃잎 형태: 가늘고 긴 타원(끝이 살짝 뾰족) 낱장이 대부분, 네 갈래 꽃은 약 20%로 크기를 조금 크게. 노랑 3톤 변주 + 연두 잎 조각 소량.
- 성능: requestAnimationFrame, devicePixelRatio 대응(최대 2), visibilitychange 시 일시정지, 저사양에서 개수 자동 감소.
- 인터랙션(유지): 갤러리 가로 스와이프 + 핀치 줌 lightbox / 계좌 복사 버튼 / D-day 카운트다운 / 음악 토글 / RSVP 폼 / 카카오 공유.
- prefers-reduced-motion 분기 필수 — 파티클 OFF(정적 장식 대체 가능), fade-in 즉시 표시.
